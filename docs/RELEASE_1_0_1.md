# Запрет VPN — выпуск 1.0.1 (3)

## Основа и объём

Локальная копия `main` из `noyponnoy/rabochiy-vpn-app`, коммит
`59b35a697a2775e9e9fcf37e1e9f3c4c156bbf61`. В новый репозиторий перенесены
исходники и поставляемые JNI-библиотеки, без результатов сборки, Kotlin-кешей,
машинных путей, журналов и встроенного значения подписи API.

В Play Console опубликован `1.0.0 (2)`, хотя исходный pubspec содержал
`1.0.0+1`. Поэтому следующая версия — **1.0.1+3**, а не повторный build 2.
Android получает оба номера из Flutter; экран настроек уже использует
`PackageInfo.version` и `buildNumber`, отдельной константы там нет.

R8 оптимизирует Java/Kotlin DEX, не Dart AOT. Для Dart обфускации нужны
`--obfuscate --split-debug-info` из README и сохранение символов. Это не
позволяет обещать прохождение порога Play: итог измеряет Console по AAB.

AGP 9 не включён: переход меняет Kotlin-интеграцию и DSL и требует проверки
совместимости Flutter и всех модулей. Без разрешённой сборки безопаснее
ограничиться 8.13.2. Рекомендация Console о переходе на AGP 9 остаётся
отдельной работой, а не выполненным пунктом.

Предварительно собранные `.so` не перекомпилировались. В исходном отчёте
Play указана поддержка 16 КБ, но это не доказывает отсутствие предположений
о размере страницы внутри native-кода. Символы от другой версии `.so`
не пригодны для расшифровки аварии.

## Обязательно перед публикацией AAB

1. Настроить JDK/Flutter/Android SDK, приватный release keystore и
   `config/build-secrets.json`. Значение подписи API согласовать с backend;
   опубликованное ранее значение требует координированной ротации.
2. Выполнить `flutter pub get`, `flutter analyze`, `flutter test`, затем
   релизную сборку по README. Проверить, что AAB подписан release-ключом:
   исходный Gradle допускает debug-подпись при отсутствии `key.properties`.
3. Проверить release/minified AWG и GW: первый VPN permission, connect,
   cancel, reconnect, смену протокола, экран off/on, повторный запуск,
   logout/delete account и include/exclude split tunneling.
4. Проверить Android 24 и актуальные Android, arm64 16-КБ-устройство,
   доступность с крупным системным шрифтом, 14 языков и длинные строки.
   Крупные шрифты по-прежнему ограничиваются исходной схемой масштабирования;
   полноценная адаптивность и accessibility не заявлены исправленными.
5. Сверить трафик после передачи >2 ГБ и длительной сессии, перезапуска и
   возврата из фона; проверить память/ANR и реальное потребление батареи.
6. Загрузить в закрытый трек. Проверить Pre-launch report, Android vitals,
   итоговые показатели R8/DEX, mapping upload и native symbolication.
7. Сверить Data safety, серверную No Logs-политику, Firebase-сбор данных,
   фактический бесплатный тариф и правила Google Play для VPN и платежей.
   Используемая внешняя страница оплаты требует проверки применимых
   региональных программ/правил: этот код не является юридическим аудитом.
8. Перенести EU-тексты и release notes из `eupage.txt`, добавить локализованные
   скриншоты. Английскую/русскую карточки из `page.txt` не заменять.

«Выбор редакции», место в поиске и отсутствие всех сбоев не гарантируются
изменением кода или описания. Обещать их без решения Google нельзя.
