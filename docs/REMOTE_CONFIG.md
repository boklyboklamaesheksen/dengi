# Remote Config: адрес API и VLESS-подписки (gwenc1)

Адрес бэкенда Запрет VPN меняется из консоли Firebase без релиза в Google
Play. Схема та же, что в GW- и VLESS-приложениях: в APK и в JSON Remote
Config нет открытых `https://…` строк, все URL закодированы в формате
`gwenc1`.

## Ключи (Firebase Console → Remote Config)

| Ключ | Тип | Значение |
|------|-----|----------|
| `encrypted_api_url` | String | Основной адрес API в формате `gwenc1:…` |
| `encrypted_api_fallback_url` | String | Необязательный резервный адрес (`gwenc1:…`) для автоматического failover. Пусто — резерва нет |
| `encrypted_vless_sub_urls` | String | Ссылки на VLESS-подписки (`gwenc1:…`). Пусто — VLESS-серверы выключены |

Новые версии приложения **не читают** открытый ключ `api_base_url`. Не
удаляйте его, пока в онлайне есть версии до этого обновления (≤ 26.10.4+8),
— они читают только его. Когда старые версии уйдут, удалите `api_base_url` из консоли:
это последнее место, где адрес лежит открытым текстом.

## Как получить значение

```bash
python3 tools/gwenc.py encode "https://новый-домен.example.com"
python3 tools/gwenc.py decode "gwenc1:…"   # проверка
```

Алгоритм `gwenc1`: UTF-8 байты → XOR с ключом
`37 5B 71 2E 49 6D 23 58 0F 66 3C 7A 11 44 69 05` (позиция `i mod 16`) →
`+0x5D mod 256` → разворот последовательности → Base64 (стандартный, с
паддингом) → префикс `gwenc1:`. Декодирование — строго в обратном порядке.

## Какие адреса принимаются

- Только `https://`. Адреса с логином/паролем, `?query` или `#fragment`
  отбрасываются, приложение остаётся на прежнем адресе.
- Можно с путём-префиксом: `https://host/prefix` → запросы уходят на
  `https://host/prefix/vpn/api/...`. Если вставить адрес целиком с
  `/vpn/api/v1/` на конце, этот хвост отрезается автоматически.
- Кириллический домен переводится в punycode автоматически
  (`пример.рф` → `xn--e1afmkfd.xn--p1ai`).
- Wildcard-шаблон `*.api.example.com` (или `https://*.api.example.com`):
  приложение выбирает на устройство случайный поддомен
  (`k3x9a0qf7d2m.api.example.com`) и меняет его при блокировке. Нужны
  wildcard-DNS и wildcard-сертификат на `*.api.example.com`.

Битое значение (опечатка, обрезанный base64) игнорируется: приложение
работает на последнем сохранённом адресе.

## Как приложение выбирает адрес

1. При старте берётся последний адрес из Remote Config, сохранённый на
   устройстве в закодированном виде (`gwenc1`, в shared_prefs нет открытого
   URL). Если его нет — зашитый закодированный дефолт.
2. Remote Config: стартовая серия запросов (3 с, 6 с, 12 с, 24 с), затем
   фоновое обновление каждые 10 минут в живом процессе, плюс real-time
   подписка — изменение в консоли доходит сразу после публикации.
   `minimumFetchInterval` в релизе — 5 минут (защита от квоты Firebase).
3. Применяется только значение, реально пришедшее с сервера Firebase
   (`valueRemote`), — дефолты не затирают полученный ранее адрес.
4. На чистой установке создание аккаунта и вход ждут первый ответ Remote
   Config до 8 секунд.

## Failover

Ошибка соединения (DNS, TCP, TLS, таймаут) или ошибка шлюза
(421, 451, 502–504, 520–530) переключает адрес и повторяет запрос один раз:

- wildcard — новый случайный поддомен (две попытки подряд, затем следующий
  адрес);
- обычный URL — по кругу: адрес из Remote Config → зашитый дефолт →
  `encrypted_api_fallback_url` → снова адрес из Remote Config.

Бизнес-ответы бэкенда (400, 404, 500) не переключают адрес. Неидемпотентные
запросы (создание аккаунта, оплата, активация кода) повторяются только если
запрос гарантированно не ушёл на сервер (DNS, отказ в соединении, TLS).

## VLESS-подписки (`encrypted_vless_sub_urls`)

Серверы из подписок показываются в общем списке после AWG и GW, с бейджем
`VLESS` и в отдельном фильтре. Подключение — встроенный Xray-core
(`XrayVpnService`).

- Значение — один или несколько токенов `gwenc1:…` через пробел, запятую
  или перевод строки. Внутри токена тоже можно закодировать несколько
  ссылок, разделённых переводом строки:
  `python3 tools/gwenc.py encode "https://mc.yarik.app/bs"`.
- Принимаются только `https://`. Открытые (незакодированные) ссылки
  игнорируются. Если в непустом значении нет ни одной валидной ссылки, оно
  отбрасывается целиком.
- Пока Remote Config не ответил, используется зашитый дефолт
  `https://mc.yarik.app/bs` (в APK он лежит в `gwenc1`).
- Тело подписки — построчный список `vless://…` или он же в Base64.
  Остальные протоколы пропускаются. Имя сервера берётся из `#remark`:
  флаг становится иконкой, остальное — названием
  («🇷🇺 Белые списки #1» → 🇷🇺 «Белые списки #1»).
- Подписки обновляются при каждой загрузке каталога и сразу после смены
  значения в консоли. Последний удачный список кэшируется на устройстве, так
  что офлайн или при блокировке источника серверы не пропадают.

## Ограничения

`gwenc1` — обфускация, а не криптография: ключ лежит в APK. Она убирает
открытый URL из строк APK и JSON Remote Config. Сам адрес всё равно виден в
DNS-запросах и TLS SNI на устройстве пользователя; от блокировок защищают
wildcard-поддомены и резервный адрес.
